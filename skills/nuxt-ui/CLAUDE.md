## Nuxt UI

- Nuxt UI **v4**. Invoke the `nuxt-ui-docs` skill before using or changing a `U*` component — training-data knowledge of props, slots and variants is stale.
- Use the `nuxt-ui-templates` skill for composition patterns (dashboard, docs, landing, saas).
- Semantic design tokens only (`primary`, `neutral`, `text-muted`, `bg-elevated`, `border-default`, …) — never raw Tailwind palette classes.
- `.claude/rules/web-vue-ui.md` loads automatically when editing `app/**/*.vue`; follow it.
