/docs · in the reading column

Callout

Glass, a green rule down the left edge and nothing else. It sits inside the 1024 reading column, at the same width as the prose.

Secrets

Bundles that need an environment variable declare it, and the tool collects every declaration into one example file.

Your .env is never touched

The tool writes .claude/.env.example and rewrites it on every run. It never creates, reads or deletes .claude/.env.

Removing a bundle

A bundle takes its own lines back out of CLAUDE.md on the next run. Anything you wrote outside the marker blocks stays where it is.
