## Docs
- Three tiers: `docs/handovers/` (what shipped and what's next, written before user hand-off and updated through acceptance), `docs/wiki/` (how the system works today, one page per system), `docs/superpowers/{specs,plans}/` (frozen intent).
- Code plus the newest handover are truth. Update the relevant wiki page in the same change that ships the behaviour; stale pages have misled past sessions.
